## 🚀 Quick Start (Local Development)

### 1. Clone the repository
```bash
git clone https://github.com/kingcs123/Chetan-Singh.git
cd Chetan-Singh
```

### 2. Install dependencies
```bash
npm install
```

### 3. Configure Environment Variables
Copy `.env.example` to `.env.local` and add your Google Gemini API key:
```bash
cp .env.example .env.local
```
Edit `.env.local`:
```env
GEMINI_API_KEY=your_gemini_api_key_here
```
*(Note: If no API key is provided, the AI persona will seamlessly use the built-in CV-grounded offline response engine!)*

### 4. Run the Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🌐 Deploying to Public Web (Vercel)

The easiest way to deploy this Next.js portfolio publicly is via [Vercel](https://vercel.com/):

1. Go to [Vercel](https://vercel.com/) and click **"Add New Project"**.
2. Connect your GitHub account and import the repository `kingcs123/Chetan-Singh`.
3. In **Environment Variables**, add `GEMINI_API_KEY` (optional for live AI responses).
4. Click **Deploy**. Your portfolio will be live at `https://chetan-singh.vercel.app` (or your custom domain) within minutes!
